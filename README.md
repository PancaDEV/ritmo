## O que dá para fazer

| | |
|---|---|
| 🏋️ **Treinos** | Fichas prontas ou suas, rotina semanal, séries com carga e repetições, cronômetro de descanso. |
| 📈 **Evolução** | Histórico por sessão e por exercício, com gráfico da maior carga registrada. |
| 🎥 **Demonstrações** | Vídeos de execução de um catálogo revisado, carregados só quando você toca. |
| 🍽️ **Alimentação** | Diário de refeições com totais por dia; o que não foi informado nunca vira zero. |
| 🔎 **Tabela TACO** | Busca de alimentos com cálculo pela quantidade consumida, inclusive offline. |
| 📦 **Código de barras** | Produtos do Open Food Facts ou cadastrados por você a partir do rótulo. |
| 🔁 **Repetir e recentes** | Repita uma refeição ou reaproveite alimentos já registrados, sempre com revisão. |

## Instalar

1. Abra **https://pancadev.github.io/ritmo/** no celular.
2. **Android (Chrome):** menu ⋮ → *Instalar app*.
   **iPhone (Safari):** compartilhar → *Adicionar à Tela de Início*.
3. Pronto: o RITMO abre como um app, inclusive em modo avião.

## Seus dados

- Ficam **só no seu aparelho** (IndexedDB do navegador). Não há conta, login nem servidor guardando seus registros.
- Faça **backup** em *Perfil → Exportar backup* e restaure quando quiser.
- Sem anúncios e sem rastreamento.

## Fontes e créditos

- **TACO** — Tabela Brasileira de Composição de Alimentos, 4ª ed. (NEPA/Unicamp, 2011).
- **Open Food Facts** — dados de produtos sob licença ODbL.
- Fonte **Sora** — SIL Open Font License (ver `licenses/`).

> Os valores nutricionais são informativos e não substituem orientação de nutricionista ou médico.
